# Frontier routing and composition

This reference is invocation guidance, not a dispatcher Skill or standing database. Current user intent, governing source and authorized phase determine the job. Existing PR #40 drafts remain unmerged historical projections; reuse their capability contracts by reference rather than copying or installing their bodies.

| Requested result | Home | Do not substitute |
|---|---|---|
| Current evidence, exact source, standing or authorization | Existing `ecos-orient`, `ecos-authority-audit`, `ecos-source-to-requirements` | Scout conjectures |
| Earned baseline plus deliberately speculative structural possibilities | `ecos-frontier-exploration` | Formal verdict or approval |
| A correspondence's hinge, consequences and distinguishing fixture | `ecos-question-forward` with Fulcrum profile | Mandatory formalization |
| One selected semantic claim tested against formal machinery | `ecos-translation-frontier` | Broader analogy hunt |
| Pronunciation/understanding of an existing expression | Formal notation helper directly | New correspondence test |
| An authorized simple next action | Existing orientation, shaped next-action and episode procedures | Any fixed research pipeline |

Mixed requests split only the materially distinct outputs and sequence an actual dependency (for example, source floor before Scout). Scout may lead to Fulcrum or Translation; Translation can expose a new question or directly return a rejection. Existing standing audit reviews consequential reuse; this package never self-promotes a candidate. Prior-art search, stress tests, provenance, intuition translation and next-probe choice are composed operations with named jobs, not new Skill identities.

Carry claim/version, source basis, previous standing, active job, evidence or discriminator, rejected alternatives and exact next route. Separate procedural guidance, discoverability, actual activation, output evidence and authority.
