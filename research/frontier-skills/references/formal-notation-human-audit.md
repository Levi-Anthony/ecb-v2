# Formal notation human-audit helper

Invoke on the first consequential introduction of unfamiliar notation, and directly for a request to explain existing notation. A Skill using notation must refer to this helper without assuming the human saw a prior private explanation. Reuse may omit the full orientation only if a meaningful introduction is available in the current context. This is a projection of an existing statement, never evidence that the statement is true or that the Principal understood it.

0. **ORIENT** — name the construct, its originating mathematical problem family, its normal job, why it appears in this particular inquiry, and the misleading inference to avoid.
1. **FORMAL / SYMBOLS** — preserve the exact expression and the definitions/domains that matter.
2. **NAME / TOKEN** — name unfamiliar symbols and state conventional pronunciation; flag overloaded conventions.
3. **SAY FORMALLY** — speak the complete expression with conventional mathematical syntax, preserving direction, quantifiers, subscripts and scope.
4. **SAY NATURALLY** — supply a smoother conversational mathematical reading where it helps, without changing the claim.
5. **READ** — explain the conceptual statement in ordinary language. This is distinct from pronouncing it.
6. **WORKED EXAMPLE** — evaluate or trace an actual small case, not just rename its pieces.
7. **SYSTEM APPLICATION** — reconnect the same expression to the exact ECOS/SIGMA claim, fixture, consequence and its standing limit. If it has no ECOS application, say so rather than invent one.

For `f*: C_I → C_J`, first define what `f*` does in the source: star alone does not determine direction. Convention might be “f star, from C sub I to C sub J”; `→` is “to” in a function type or “maps to” in a mapping assertion. `∀` is “for every”; `∈` “is an element of”; `⊆` “is a subset of”; `⇔` “if and only if”; `∅` “the empty set”; `∘` “composed with” with the declared right-to-left convention. Explicitly speak superscripts, primes and subscripts. Verify the toy case respects the chosen definitions and direction.

If notation is undefined, ask for or recover its convention before presenting a confident interpretation. If the expression itself is defective, preserve its edition, name the defect and route the substantive correction to the authoring/evaluation contract. An apparent teaching success is not direct evidence of human comprehension.
