**What “f star” means.** `f*` is pronounced “f star.” The star usually marks an operation derived from `f`; by itself, it does not say what the operation does or which way it goes. In mathematics, a pullback named `f*` often goes opposite the direction of `f`. We need the source's definition and type, such as `f*: C_I → C_J`, before identifying this particular operation. That type is read “f star, from C sub I to C sub J”; it says an input in `C_I` yields an output in `C_J`. The arrow specifies the direction, while the meanings of `C_I`, `C_J`, and the star still need definitions. In ordinary terms, it is a rule taking an item from one specified collection to another, if the source indeed defines it that way. A notation explanation cannot certify that the rule models permissions.
