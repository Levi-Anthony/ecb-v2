## Opened holdout application without revision

**H07, field survey map — selected formal claim.** This invented case stipulates a source interface with `survey-location` and a destination use that also requires `publication-consent`. The exact claim “change of index transports every relevant obligation” is false in the stipulated case: two destination accounts can share the same surveyed-location receipt while differing on consent; restriction to the source interface cannot distinguish them. This is a countermodel to full destination coverage, while exact record transport may remain valid under a qualified comparison. It does not prove a real survey's consent rules. The word “obligation” is not silently replaced by a receipt: the destination obligation is stipulated separately, and the record is only candidate evidence toward it. If the destination genuinely has no extra obligation or a complete, qualified semantic bridge supplies it, this particular counterexample no longer applies. No formal ontology or governance changes follow.

**H09, maintenance notation only.** `g: X → Y` is conventionally a function from X to Y; say “g, from X to Y.” It names input/output sets and an assignment rule, but the expression alone does not specify g's rule or what X and Y denote in a maintenance inspection. A toy `X={pass, fail}`, `Y={0,1}`, `g(pass)=1`, `g(fail)=0` shows one possible rule; that invented rule cannot be substituted for the source's actual g. First-use orientation: function notation comes from mathematical descriptions of mappings; its normal job is to specify domain/codomain and then the mapping rule, not to certify an inspection. Conceptually it maps each admissible input to an output. The system application is unknown until the inspection's definitions are recovered; no ECOS-specific authority is implied. This direct teaching request does not activate Translation.

**H13, hiking diversion — mixed near miss.** No actual baseline source or old approval accompanies the invented prompt. The proper first result is AUDIT with an evidence-floor HOLD and a request for the approval, scope and diversion conditions. The conditional Scout step cannot produce a justified candidate from that empty floor. This is a good non-activation of the exploratory result, not a failure to brainstorm.

**H10, library catalog notation — direct notation.** `A ⊆ B` is read formally “A is a subset of B”; `⊆` permits equality. A toy `A={book 1}`, `B={book 1, book 2}` satisfies it; `A={book 3}` does not. The construct is set inclusion, from set theory, normally used to compare membership coverage. Here it could compare two collections of cataloged records if those collections are what A and B were defined to mean. It does not establish that a catalog revision is complete or authorized. No formal correspondence probe is warranted.
