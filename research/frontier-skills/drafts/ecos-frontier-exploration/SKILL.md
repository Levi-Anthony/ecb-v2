# Frontier Exploration / Scout

This procedural projection does not change governing semantics or authorize a decision. Current sources and explicit instructions govern. Preserve the user's exact referent, claim, definitions, dependencies, purpose and standing.

## Activation and result

Use when there is an earned evidence floor and exploration beyond it is requested. If that floor is missing, recover the decision-bearing sources and audit first; do not manufacture it. An already selected formal claim belongs to Translation Frontier. An evidence/standing question belongs to existing authority audit. A simple next action should proceed directly. Read [routing and composition](../../references/routing-and-composition.md) when intent is mixed.

1. State the baseline with source and edition, the protected meaning, the target decision and the allowed speculative reach. Note what is unresolved, without treating it as disproved.
2. Seek candidate correspondences, mechanisms or prior-art neighborhoods because they might explain an observed relation, generate a discriminating test or reveal a useful tool. Search prior art on demand; source prestige does not validate the mapping. Positive repeated fit is evidence worth harvesting before adversarial testing, but does not promote standing.
3. For each survivor, record **candidate**, **why interesting**, **expected leverage for the named decision**, **imported assumptions and earliest likely mismatch**, **SPECULATIVE standing**, **source/provenance**, and **fulcrum lead or discriminator**. Differentiate actual inherited constraints from new conjectures. Keep rejected candidates and reasons when consequential.
4. If none survives scrutiny, return **zero useful candidates** with the search envelope and why; do not invent a branch to fill a template.
5. Hand a selected hinge to the [Fulcrum Inquiry profile](../../references/fulcrum-inquiry.md), a selected exact formal test to Translation Frontier, or competing next probes to existing orientation, Question Forward and shaped-next-action composition. A candidate cannot endorse itself; route any standing update to existing evidence/authority audit and the governing acceptance path.

Stop when further breadth would not change the branch decision, unless the commission explicitly asks for a wider search. The result is exploratory, not established ontology, production design or action authority.
