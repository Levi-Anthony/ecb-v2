## 2. Precedence rules

When two artifacts appear to disagree:

1. A later explicit Principal disposition governing the same proposition overrides earlier lower-standing wording.
2. `docs/invariants.md` governs constitutional interpretation until explicitly changed through its recorded route.
3. A later accepted semantic repair supersedes an earlier semantic claim at the same scope.
4. Architecture/implementation evidence may operationalize a semantic contract but does not widen its scope by successful operation alone.
5. Historical detail remains history unless explicitly current.
6. Formal elegance or proof inside a model does not create semantic authority.
7. Currentness must be explicit; newest does not mean current.
8. This index never outranks the source it indexes.

## 5. Current semantic lineages

### Level

Current governing semantic core:

> **Level is identified through asymmetric existence dependency together with constitutive organization: what must exist, and in what organization, for the designated whole to exist as that whole?**

Not sufficient by themselves:

- generic containment;
- size;
- complexity;
- prestige/rank;
- developmental attainment;
- a “higher/lower” label.

Current operational lineage:

working URG core → ECO-179 preservation → ECO-51 written seating/checker procedure → ECO-185 PGO-adequacy/reseating repair.

**Current standing:** sufficient for present Register-B descent; formal consolidation is the next job.

### Quadrant

Current generator:

1. **constitutive seat** vs **participatory seat**;
2. **governing possibility/dependency burden** vs **determinate-case burden**.

Ordinary traversal preserves the same focal referent R.

Changing what counts as constituent is boundary revision / re-individuation, not ordinary quadrant traversal.

Current lineage:

working URG core → qualified v0.2 / ECO-143 → C1–C6 architecture / ECO-147 → ECO-179 later clarification.

**Current standing:** v0.2 remains the strongest bounded qualified semantic contract; ECO-179 clarifies and supplies program/closure context rather than silently replacing it.

### Direction / Capacity

Current accepted architecture from ECO-184:

Two opposed directional axes:

- agency / self-preservation ↔ communion / self-adaptation;
- transcendence ↔ dissolution.

“Directional” means **relational transformation**.

Modal views over the same coordinate:

- tendency = neutral structural description;
- capacity = transformation available/supported for R under declared conditions;
- drive = that directional possibility actively mobilized / exerting pressure.

Open:

- whether the four are exhaustive at the intended abstraction;
- exact mathematical representation;
- whether Drive ever requires semantics beyond mobilized capacity.

## 10. Reentry / contradiction rules

Reenter ECO-220 or its successor reconciliation surface when any of these occurs:

- a source marked current here is superseded;
- two accepted sources impose materially incompatible obligations;
- a cold reader cannot determine which source governs;
- an axis-local contract requires an unrecorded primitive;
- a formal witness falsifies a load-bearing semantic/architecture premise;
- a human-door projection diverges from the structured source system;
- a new formalization changes the role taxonomy or derivation edges;
- an implementation makes a required distinction unrecoverable.

Do **not** reenter merely because:

- a new example appears;
- terminology is inelegant;
- a formal analogy is attractive;
- a source is newer but not governing;
- implementation prefers another storage shape.
