## SHAPE TASKS

Freeze, before generation:

### A. Idealized end state

Describe the first-class naming outcome from the user/operator perspective and work backward to the required properties. The name should be capable of becoming an effortless system address, not merely an accurate heading.

### B. Hard rejection gates

Convert the semantic safety floor into pass/fail rejection conditions. A material failure cannot be averaged away by memorability, cleverness, resonance, or brand appeal.

### C. First-class identity floor

Define minimum requirements for pronounceability/invocation, memorability, corpus discrimination, compositional prose use, durability under architecture growth, and sibling coherence with SIGMA/ECOS/BRAIN without mimicry.

### D. Multiplicative-value dimensions

Define how to recognize surplus value that is allowed to improve a surviving candidate: disciplinary teaching, layered honest meanings, symbolic/etymological resonance, form-function isomorphism, productive visual identity, verbal morphology, cross-scale utility, or analogous emergent gains.

These are multipliers only after the semantic and identity floors pass.

### E. Naming-method families

Freeze eligible generation lanes without producing names. Include at minimum:

* forward-derived real-word acronym / disciplinary expansion;
* layered acronym or brand expansion;
* established real-word appropriation / bounded metaphor;
* earned coinage / transformed word;
* opaque proper noun;
* scientific/symbolic/linguistic borrowing.

Specify what evidence or constraints each lane must satisfy and how to prevent one lane from dominating merely because SIGMA succeeded there.

### F. Generation independence / anti-anchoring

Define how the later Generate phase will produce meaningfully independent candidate families before cross-comparison. Incumbents and `Orienting Composition` are test subjects, not privileged seeds.

### G. Qualification and Overshoot protocol

Freeze the exact test surface for later candidates, including:

* reduced-context expectation;
* semantic/structural fit;
* procedure/object/materialization/currentness/authority distinctions;
* multiple materializations and no-current states;
* unresolved authority;
* recursive/map-assessment use;
* conversational and spoken use;
* abbreviation/pluralization/verb morphology;
* internal corpus collision and semantic retrieval;
* external term-of-art / inherited-meaning collision;
* literalized metaphor;
* lifecycle/supersession;
* sibling-system confusion;
* false activation;
* human memorability/enjoyment and recognition limits.

### H. Selection architecture

Define the role of formal qualification vs Principal/human recognition. Do not turn selection into a weighted score that can hide a material failure. Preserve a `none qualifies` outcome.

### I. Naming interface

Define what a selected result must return: proper name, descriptor, ordinary prose form, allowed expansion(s), abbreviation only if earned, pronunciation if non-obvious, alias/supersession treatment, and machine identifier only if separately warranted.

### J. Stopping rule

Shape closes when a cold worker could enter Generate without inventing evaluation criteria, silently privileging an incumbent, or confusing first-class identity with semantic definition.
