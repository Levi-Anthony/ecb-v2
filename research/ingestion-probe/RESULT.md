## 2. Register B recalibration

The single governing amendment is **Register B — bounded learning through action** in the Build
Contract. START_HERE links to it. The commission provenance is in `COMMISSION.md`.

It installs: sufficient current coherence → qualified bounded Move → retained observation → explicit
model update. Intent, authority, bounded effect, observability, acceptable/recoverable failure and
interpretability are the qualification floor. Questions block only when materially affecting that
floor or evidence usefulness. Question Forward selects reasoning, retrieval, observation or
intervention instead of requiring uncertainty to disappear.

The Principal's subsequent correction is explicit: **a missing tool needed for an authorized
operation is sufficient evidence to commission a bounded instrument**. Recurrence counts or a
completed ontology are unnecessary. Tools remain subject to the same authority/effect floor.

Superseded behavior: treating uncertainty as a universal pre-action gate, exhaustive Shape as a
prerequisite, or tool absence as a reason to accumulate manual workarounds. Existing wording that
already permits deterministic physicalization without repeated incidents was preserved. Review found
no conflict with authority/promotion rules, frozen acceptance gates, identity ADRs, BUILD 7's
capacity-versus-resolution distinctions, or BUILD 11's pending consumer cutover. Invariants,
standing, evidence, lineage, recovery and genuine human gates remain unchanged. No axes were removed.

## 5. Model delta

**Strengthened:** an annotation separate from raw evidence can carry people, particular situations,
non-holonic relations and unanswered questions without minting identities. Existing hosting and
OpenRouter support a small evidence-producing tool without a new vendor. Deterministic source and
authority boundaries can be physicalized now.

**Falsified for this candidate:** general extraction instructions plus valid JSON are sufficient
for dependable ingestion preparation. A more explicit prompt still omitted the pronoun participant
and blurred report modality. An exact source excerpt is not proof that its description is warranted.

**Weakened:** prompt-carried orientation alone will reliably calibrate Question Forward. Several
questions pursued relational significance instead of the immediate information/currentness gap.

**Instrumentation insufficient:** the generic list does not expose missing participant coverage,
report-versus-performance errors, a relation's complete evidence path or question sufficiency as
machine-checkable obligations. A question plus a relevance sentence is not a complete wired QF
sensor: notice mechanism, re-entry and consequence remain absent. Model output needs a separately
qualified coverage/disposition check; that does not imply semantic correctness is fully mechanical.

**Not tested:** vector embedding of these fixtures, live v2 registration/claims writes, recursive
return, activation/retraction against durable identities, or full quadrantic/QLLST mapping. Existing
embedding capability was recovered rather than replaced; this run does not demonstrate its use.
