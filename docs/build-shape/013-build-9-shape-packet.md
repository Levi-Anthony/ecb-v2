## Accepted bounded capability

The accepted BUILD 9 Shape freezes one serial, disposable, non-amending recursive-self-application capability:

> A retained parent inquiry binds one exact decision-bearing governance dependency. A child inquiry may open only when resolving that dependency can materially change the parent's legitimate next step and cannot safely be discharged at parent resolution. The child returns an inspectable judgment to that exact dependency only. The parent then performs an independent predecessor- and basis-sensitive reentry disposition: `CONTINUE`, `REQUALIFY`, `REORIENT`, or `HOLD + Question Forward`.

The real recursive seam is independent parent reentry, not technical nesting or self-reference.

`child result ≠ parent permission`

`reflection ≠ authority`

`PASS ≠ CONTINUE`

`FAIL ≠ automatic REORIENT`

## Frozen behavioral mechanism

### M1 — Bind the parent decision

Retain parent inquiry/version identity, focal Referent, initiating contrast/discriminator, proposed next step, exact governing/decision basis, exact decision-bearing dependencies, parent decision Claim, unresolved proposition, admissible answer branches and differing consequences, suspension/reentry conditions, observation/freshness rules, child remit, stopping rule, and unresolved-question route.

A dependency slot is a locator into this retained contract and references the canonical dependency Claim plus exact component/version. It is not a second truth store.

### M2 — Open one bounded child and suspend dependent continuation

Child opening binds the exact parent version/predecessor, dependency Claim/slot, focal component/version, child question, criteria/method basis, remit, and consequence test. Opening and suspension are one accepted transition for the bounded specimen. One active child and one child depth are admitted.

### M3 — Retain bounded child judgment

The child judgment retains exact participation, proposition, evidence, criteria, method, attribution/remit, obligation-level findings/witnesses/limits, and typed outcome. Method/criterion change creates a newly bound attempt/contract rather than mutating old evidence.

### M4 — Return to the exact dependency

Returned judgment must match exact child contract, attempt, parent version, dependency, component/version, proposition, and scope. It supports only the named dependency and cannot replace the whole parent basis.

### M5 — Independently disposition parent reentry

Parent reentry re-observes the complete declared decision-bearing state and records one independently inspectable disposition against the exact predecessor and basis:

- `CONTINUE` — result supports the required branch and every independently required parent condition remains applicable and observed.
- `REQUALIFY` — focal inquiry still applies, but a decision-bearing basis/version/method/criterion/dependency/remit/current reliance changed or continuity is unresolved.
- `REORIENT` — a supported finding defeats the current framing, discriminator, scope, or proposed step.
- `HOLD + Question Forward` — missing/contradictory/stale/unavailable evidence, observation, remit, or result prevents a supported next disposition.

### M6 — Preserve history and restart

Read-only recovery reconstructs established transition history and presently supported routes. Replay is observational and cannot mint a new transition or recover stale permission. New reentry uses a new request bound to current predecessor and observations.

## Recursion threshold / anti-regress

Open a child only when:

1. the exact unresolved dependency is named;
2. at least two admissible answers produce different legitimate parent next-step consequences;
3. parent-level evidence/interpretation cannot discharge the uncertainty at required resolution;
4. a bounded admissible inquiry path can discriminate the branches.

Do not recurse when the uncertainty cannot change the proposed next step, another dependency independently blocks the step, the needed witness is already locally checkable, or the same question is merely repeated without new evidence/discrimination.

Stop when the bounded proposition is supported, no unresolved issue can change the active next step, or admissible evidence/remit is unavailable. Unavailability yields HOLD/QF, not success.

One child depth / one active child is a BUILD 9 proof boundary, not a universal recursion law.

## Temporal / causal disposition

No epoch, universal tick, Lamport clock, vector clock, nested-state ontology, or general temporal mechanism is earned.

The serial specimen relies on retained transition identity, explicit predecessor, exact version/dependency history, declared observation closure, and a protected reentry conflict/serialization boundary.

Preserve:

- current ≠ newest;
- change-and-restore does not erase the intervening change;
- missing observation coverage yields HOLD rather than inferred continuity;
- unrelated evidence/audit-time changes do not automatically force requalification;
- wall time is audit metadata unless an independently supplied rule explicitly uses time.

Dormant activation falsifier: overlapping independent children whose causal relation cannot be reconstructed faithfully from current predecessor/dependency/history state. Overlap is outside this capability.
