# ECB v2 — BUILD Evidence Ledger

This ledger preserves attested candidate architectural evidence before the BUILD makes decisions that the evidence may constrain.

It is not canonical doctrine, a schema migration, a frozen acceptance test, an ADR, or implementation authorization.

Source provenance for the records below: human-attested ingestion payload received 2026-09-04 America/Phoenix, titled **“ECB v2 — BUILD Evidence Ingestion Payload: Sense / Shape / Execution / Epistemic / Governance Sharpening.”**

## Ingestion contract

Every evidence record preserves at minimum:

- **ID**;
- **CLAIM**;
- **CANDIDATE STANDING**;
- **AFFECTED ARCHITECTURAL ZONE**;
- **BUILD CONSEQUENCE**;
- **FALSIFIER / FORWARD QUESTION**;
- **PROMOTION STATUS**.

An affected BUILD decision should consult applicable records during Sense before closing the decision surface. Consultation creates an evidence-consideration obligation only. It does not confer authority or require promotion.

Do not preload the full ledger when the current Move does not implicate it.

Do not convert coherence among several evidence items into authority by accumulation.

Promotion routes remain separate:

- candidate invariant → explicit invariant governance / human authorization;
- contract sharpening → governing contract revision through the appropriate BUILD route;
- acceptance-test candidate → freeze in `docs/acceptance-tests.md` before implementation is judged by it;
- local architectural closure → ADR with reopening condition;
- unresolved consequential question → `docs/open-apertures.md` when its openness itself has earned governed standing;
- useful but unpromoted evidence → remains here.

## Governing orientation carried by the payload

Candidate synthesis only:

- Freedom governs resolution.
- Control governs structural completeness.
- Awareness governs whether the system can tell what its mechanisms can actually know, enforce, observe, and revalidate.
- Reduced detail does not imply omitted structure.
- Unresolved does not imply open now.

This synthesis has **EVIDENCE** standing only.

## Candidate synthesis

The payload identifies three emerging integrity classes:

- **Closure integrity** — proceeding because orientation is sufficient without claiming uncertainty is exhausted.
- **Transformation integrity** — stating what a transformation must preserve and potentially verifying that it did.
- **Standing integrity** — distinguishing performing, observing, mapping, authorizing, qualifying, validating, and closing so computational participation cannot manufacture governance authority.

Candidate directional chain:

`Master Key → Question-Forward Sense → explicit Sense closure → adversarial Shape → preservation + falsification + reopen conditions → Output Contract → Move → checked evidence/receipt → Metabolize → evidence-bearing return → qualification → possible revalidation`

The chain is preserved here as candidate synthesis only. It does not supersede the current BUILD contract or SSMM doctrine unless separately promoted.
