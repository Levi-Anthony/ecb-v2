# ECB v1 Harvest Ledger

ECB v1 is evidence.

Do not port because a feature exists.

Record what behavior earned survival.

## KEEP

Capability must survive recognizably in v2.

For every item record:

- CAPABILITY
- PROBLEM SOLVED
- ACTUAL USE
- WHY VALUABLE
- MINIMUM SURVIVING BEHAVIOR
- V1 EVIDENCE / LOCATOR

## REBUILD

Behavior is valuable; implementation is not.

Record the same fields plus:

- WHAT FAILED IN V1 IMPLEMENTATION

Do not prescribe the v2 replacement here.

## ARCHIVE

Historical/source value survives. Runtime obligation does not.

Record:

- WHAT IS PRESERVED
- WHY IT DOES NOT BELONG IN V2 RUNTIME
- SOURCE LOCATION

## DROP

Maintenance cost or complexity exceeded demonstrated value.

Record:

- WHAT IS DROPPED
- EVIDENCE
- WHY
- REINTRODUCTION TRIGGER, IF ANY

Never ask: “Can we port this?”

Ask: “Has this behavior earned existence in v2?”
