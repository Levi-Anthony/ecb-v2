# ADR 008 — BUILD 7–10 production promotion status

**Status:** Accepted currentness / promotion-planning decision  
**Date:** 2026-09-18 America/Phoenix  
**Controlling reconciliation:** Linear ECO-150  
**Related active implementation:** ECO-149

## Decision

Treat BUILD 7–10 as **closed Register-B capability proofs whose historical implementations remain executable evidence, not pending canonical migrations**.

Future production work will promote the accepted capability responsibilities from the **current** ECB v2 production substrate using new forward migrations/interfaces where earned.

Do not canonically install the historical BUILD 7–10 SQL merely to eliminate the migration-ledger gap.

## Evidence basis

The closure receipts establish each Build as human-closed at Register B while explicitly withholding canonical installation.

The historical implementations themselves contain bounded proof constraints:

- BUILD 7: fixture-only installation; synthetic scope; `G_TEST` designation authority.
- BUILD 8: disposable atomic-ledger synthetic target; `A_TEST`; `advance_one`.
- BUILD 9: synthetic BUILD-7 scope; synthetic-inspection-only remit.
- BUILD 10: disposable bounded semantic transfer; finite specimen checker; no standing/adoption/currentness/authority/permission/effect.

BUILD 11 was later qualified against B0–6 and explicitly installed without installing BUILD 7–10. BUILD 12 + ECO-138/140 then extended that current production substrate.

## Enduring capability interpretation

### BUILD 7

Enduring job: form/resolve a scoped governing orientation against versioned structural grammar, qualify it, establish scoped currentness through separately resolved standing/authority, recover it cold, and requalify on material dependency change.

The old “Master Key object” framing is not carried forward as authority. Current PGO understanding is compositional: a materialized representation may carry/resolve governing information but does not create authority.

### BUILD 8

Enduring job: bind a qualified current orientation and separately resolved authorization to a bounded consequential action envelope with exact lifecycle/retry/effect reconciliation.

The synthetic `advance_one` target and `A_TEST` grant are proof fixtures, not production semantics.

### BUILD 9

Enduring job: bounded recursive inquiry from a material unresolved parent dependency through child discrimination and explicit parent reentry, preserving basis/current applicability.

Synthetic scope/remit constraints are proof fixtures.

### BUILD 10

Enduring job: exact semantic/custody transfer across a boundary with provenance, acknowledgement uncertainty, destination-side checking and no automatic adoption.

The finite latency/threshold checker is a specimen and should not become the universal semantic-transfer language.

## Dependency decision

Full URG completion is not a standing prerequisite for production promotion.

BUILD 7' requires only a sufficiently stable, versioned URG/PGO interface for:
- focal Referent + boundary;
- governing orientation/use;
- exact structural grammar version;
- standing/currentness/authority separation;
- dependency and requalification semantics;
- recoverable optional PGO representation that does not create authority;
- downstream orientation interface for BUILD 8'/9'.

If those semantics cannot be versioned independently of unresolved URG distinctions, ECO-150 must surface that as a real broader dependency.

BUILD 8' and BUILD 9' are downstream of BUILD 7'.

BUILD 10' is an adjacent lane and may advance when its own real transfer use/interface dependencies are satisfied.

## Current substrate reuse

Promotion must map responsibilities against B11/B12/ECO-138/140 before creating new machinery.

Expected reusable current services include:
- BUILD-11 operation identity/replay/conflict/recovery;
- BUILD-11 ordinary capability confinement;
- BUILD-12 immutable text Artifact custody;
- native Referent/Claim/Evidence Link/standing history;
- ECO-138 admission/disposition history;
- ECO-140 current shaped projection, without treating ACTION/HOLD as effect authority.

## Historical preservation

Do not rewrite historical BUILD 7–10 migration bytes to make them look production-ready. Their boundedness is part of the evidence.

Use RETAIN / ADAPT / REPLACE / RETIRE classification under ECO-150 to determine production realization.

## What would reverse this decision

Reconsider this ADR if:
- a historical BUILD 7–10 migration is shown to have been explicitly designed as a parameterized production migration rather than a proof fixture;
- current PGO/URG work falsifies the underlying capability responsibility rather than only changing its representation;
- later substrate fully absorbs a responsibility with no residual production job;
- or canonical installation of an old migration is shown to be the only coherent way to preserve an accepted invariant on the current substrate.

Absent such evidence, migration-file chronology is not an installation plan.
